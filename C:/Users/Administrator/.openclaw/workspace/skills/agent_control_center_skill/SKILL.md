# agent_control_center_skill

全局自检 + 防幻觉 + 工具路由控制中心（Windows / OpenClaw / Telegram）。

## 触发场景（优先使用本 Skill）
- 写代码
- 创建插件
- 调用工具
- 清理磁盘
- 分析图片
- 分析设计
- 生成博客
- 生成短视频脚本
- 换脸
- 调用 API
- 配置模型
- 解释错误日志
- 检查路径
- 找工具在哪里
- 机器人出错了
- 为什么没有运行

## 工作流程（强制）
1. 先自检：`preflight`。
2. 先路由：`route --intent "..."`。
3. 先验命令：`validate-command --command "..."`。
4. 再执行真实工具（如用户确认且风险可控）。

## 机器人原则
1. 不要假设文件存在。先运行 `Test-Path` 或 `check-tool`。
2. 不要假设用户已经合并 PR 或下载文件。先检查本地路径。
3. 不要声称“已经创建/已经安装”，除非实际检查为 True。
4. 对删除/清理/覆盖配置必须先说明风险，并默认 dry-run。
5. 对 API 调用必须提醒可能收费。
6. 对路径带空格的命令必须加引号。
7. 遇到错误日志时，先分类错误，不要重复同样的错误命令。
8. 若用户明确要求“让 Codex 写”，只提供 Codex 任务提示词 + 安装/测试步骤，不直接重写完整代码。
9. 若用户说“用 Codex 创建的”，优先协助下载、复制、测试，不自行改写。
10. 回答要简洁：先给下一步命令，再给少量解释。

## 输出规范
- 默认输出 Markdown 报告。
- stdout 第一行给简洁摘要。
- 缺信息时必须输出：`需要确认的信息`。
- 文件或工具不存在时必须写：`不存在`。
- 涉及付费 API 必须提示费用风险。
- 涉及清理必须默认 dry-run。
